# 3. Этапы разработки

Принцип нарезки: каждый этап заканчивается состоянием, которое **можно показать пользователям и заработать на нём**. Никаких «этап 2 — доделываем то, что не влезло в этап 1».

---

## Этап 0. Фундамент

Инфраструктура, без которой остальное будет переписываться.

- Репозиторий, CI (lint + typecheck + tests), Docker Compose (Postgres, Redis, MinIO).
- Prisma-схема и первая миграция, сиды справочников.
- Валидация `initData` → JWT, роли, middleware защиты роутов.
- Дизайн-система из Figma: токены (цвета, типографика, радиусы, отступы), базовые компоненты shadcn/ui.
- Скелет бота: `/start`, deep-link, кнопка запуска Mini App.
- Sentry, структурные логи, `/health`.

**Готово, когда:** пользователь открывает Mini App из бота, видит свой профиль, роли работают, CI зелёный.

## Этап 1. MVP — «выполнил → получил деньги»

Полный замкнутый цикл. Это то, что запускается в прод.

### Mini App

- Каталог заданий: фильтры по сложности / категории / награде, сортировка, поиск, пагинация.
- Карточка задания: описание, пошаговая инструкция, награда, бейдж сложности, «≈ время одобрения», требования к пруфам, лимиты.
- Взятие задания (`DRAFT` + таймер `completionTtlMins`) с проверкой лимитов и таргетинга.
- Отправка пруфов: фото (multi-upload), видео, текстовый комментарий. Presigned-загрузка в S3, прогресс, retry, клиентское сжатие изображений.
- «Мои задания» с табами по статусам и таймлайном каждого выполнения.
- Профиль: баланс (`available` / `pending` / `hold`), история операций, статистика.
- Вывод: RUB на карту/СБП и USDT (TRC-20). Сохранение реквизитов, расчёт комиссии, проверка минимальной суммы.
- Уведомления: колокольчик с бейджем, список, детали, «прочитать всё».
- Рефералы: ссылка, QR, список приглашённых, начисления, статистика.

### Бот

- `/start` с приёмом `ref_<code>`, привязка реферала.
- Дублирование важных уведомлений (одобрено / отклонено / выплачено / выплата отправлена).
- `/balance`, `/tasks`, `/support`.

### Админ-панель

- Офферы: список с фильтрами, создание, редактирование, публикация/пауза/архив, дублирование.
- **Ручное переопределение сложности и времени одобрения** с бейджем «вручную» и кнопкой сброса к авто.
- Очередь модерации: пруфы, просмотр медиа, одобрить / отклонить (с причиной из справочника) / на доработку, горячие клавиши, лок выполнения за модератором.
- Выплаты: очередь заявок, одобрение, отметка «отправлено» с TX/референсом, отклонение с возвратом средств.
- Пользователи: поиск, карточка, ручная корректировка баланса (с обязательным комментарием), блокировка.
- Дашборд: заданий на модерации, нарушенный SLA, заявок на выплату, выручка/расход за период.

### Бэкенд

- Домены: offers, submissions, wallet, withdrawals, notifications, referrals.
- Леджер с идемпотентностью и `Serializable`-транзакциями.
- Воркеры: `hold-release`, `notification-dispatch`, `stats-rollup`, `expire-submissions`.
- Ручное добавление офферов (интеграции сетей — следующий этап).
- Выплаты в MVP — **ручные**: админ отправляет деньги и фиксирует референс. Крипто-автоматика приходит на этапе 3, потому что ручной процесс на первых сотнях выплат дешевле и безопаснее автоматики, которую никто ещё не обкатал.

**Критерии приёмки MVP:**
1. Пользователь проходит путь от каталога до денег на балансе без участия разработчика.
2. Модератор обрабатывает выполнение за ≤ 15 секунд на типовом кейсе.
3. Двойное начисление невозможно (тест на конкурентные постбеки).
4. Все важные события приходят и в Mini App, и в бот.
5. Сверка `SUM(ledger)` = `wallets.available` проходит на проде.

## Этап 2. Интеграции сетей и автоматизация модерации

- **Адаптеры GetBlogger, Leadgid, Rafinad**: единый внутренний контракт `NormalizedOffer`, маппинг полей, инкрементальный синк по расписанию.
- Уважение `MANUAL`-полей при синке + отчёт «что изменилось» после каждого прогона.
- Автоклассификатор сложности и ETA (эвристика по числу шагов, требованиям пруфов, награде, категории).
- Приём постбеков сетей → автоподтверждение конверсий по `clickId`.
- Автоодобрение по правилам (доверенный пользователь + оффер с `autoApprove` + низкий риск).
- Антифрод v1: правила дубликатов, всплесков, общих IP/устройств; `riskScore` и приоритизация очереди.
- Массовые действия в модерации, шаблоны отказов, OCR-подсказки по скриншоту.
- Аналитика офферов: конверсия, доля отказов, реальный ETA, маржа.

## Этап 3. Автоматические выплаты

- **Крипта:** изолированный payout-signer, hot/warm-кошельки, whitelist адресов, суточные лимиты, мониторинг подтверждений через вебхуки, автосмена статуса `SENT` → `COMPLETED`.
- **RUB:** интеграция платёжного шлюза для выплат на карту/СБП.
- Пакетные выплаты, автоодобрение до порога суммы, второй аппрув сверх порога.
- Курсы RUB→USDT с несколькими источниками и защитой от аномалий.
- Сверка балансов кошельков и алерты на расхождения.

## Этап 4. Рост и удержание

- Геймификация: уровни, ачивки, ежедневный бонус, стрики.
- Реферальная программа v2: многоуровневые тиры, конкурсы, лидерборды.
- Персональные подборки заданий (ранжирование по истории пользователя).
- A/B-тесты каталога и карточки задания.
- Поддержка внутри Mini App (тикеты) и `/support` с эскалацией.
- Локализация (RU/EN/UZ/KZ), мультивалютность.
- Push через Telegram-каналы, реактивация спящих пользователей.

---

## Этап 5. Масштаб и зрелость

- Вынос payout-service и bot-gateway (по триггерам из §1.6 архитектуры).
- ClickHouse + BI-дашборды, партиционирование леджера.
- SLA-мониторинг модерации, автобалансировка нагрузки между модераторами.
- Публичное API / white-label.
- Прохождение внешнего аудита финансового контура.

## 3.1. Что сознательно НЕ входит в MVP

| Отложено | Почему |
|---|---|
| Автоматические крипто-выплаты | Ручные выплаты на первых сотнях заявок дешевле и безопаснее; автоматика без обкатанного процесса — прямой путь к потере средств |
| API-интеграции трёх сетей | Ручное добавление офферов даёт запуск раньше; интеграции требуют доступов и песочниц, которых на старте обычно нет |
| Полноценный ML-антифрод | Нужны данные. Сначала собираем сигналы (`fraud_flags`), потом учим |
| Мультиязычность | Первый рынок — RU. Строки сразу через i18n-словарь, но перевод один |
| Свои push-уведомления | Telegram-бот покрывает потребность бесплатно |
